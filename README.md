# 📚 Tech Bonder — Estuda que Cola

Um quiz escolar interativo desenvolvido com **HTML, CSS e JavaScript**, criado para testar conhecimentos de forma divertida e educativa.

## 🎯 Sobre o Projeto

O Tech Bonder é um jogo de perguntas e respostas que permite aos usuários escolher uma matéria escolar, responder a cinco perguntas e conferir o resultado ao final do desafio.

## ✨ Funcionalidades

- 🏠 Tela inicial com apresentação do projeto.
- 📚 Seleção entre oito matérias escolares.
- ❓ Cinco perguntas por matéria, com quatro alternativas cada.
- 🔀 Alternativas embaralhadas aleatoriamente.
- ✅ Correção automática das respostas.
- 🎨 Feedback visual para respostas corretas e incorretas.
- 🏆 Resultado final com a pontuação do jogador.
- 🔄 Opções para reiniciar o quiz ou voltar ao início.
- 📱 Layout responsivo para computadores e celulares.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estrutura das telas e dos elementos do quiz.
- **CSS3:** cores, gradientes, botões e layout responsivo.
- **JavaScript:** perguntas, alternativas, pontuação e navegação entre telas.

## 📁 Estrutura dos Arquivos

```text
tech-bonder/
├── index.html
├── style.css
└── script.js
```

- `index.html`: estrutura das telas e dos botões.
- `style.css`: estilos e responsividade.
- `script.js`: perguntas, respostas e funcionamento do jogo.

## 🚀 Como Executar

### No CodePen

1. Acesse https://codepen.io/.
2. Crie um novo projeto.
3. Cole o HTML na área HTML.
4. Cole o CSS na área CSS.
5. Cole o JavaScript na área JS.
6. Execute e comece a jogar.

### No computador

1. Crie uma pasta para o projeto.
2. Adicione os arquivos `index.html`, `style.css` e `script.js`.
3. Copie os códigos correspondentes para cada arquivo.
4. Abra o `index.html` no navegador.

## 🎮 Como Jogar

1. Clique em **Começar Quiz**.
2. Escolha uma das oito matérias.
3. Leia a pergunta e selecione uma alternativa.
4. Veja se acertou ou errou.
5. Avance até responder às cinco perguntas.
6. Confira o resultado final.
7. Escolha outra matéria para continuar aprendendo.

## 📊 Sistema de Pontuação

Cada matéria possui cinco perguntas. O sistema contabiliza os acertos e erros e apresenta uma mensagem de acordo com o desempenho.

- 🏆 **Pontuação máxima:** todas as perguntas corretas.
- 👏 **Bom desempenho:** pelo menos metade das perguntas corretas.
- 💪 **Continue praticando:** menos da metade das perguntas corretas.

O projeto tem como objetivo tornar o aprendizado mais divertido e ajudar os estudantes a praticar conhecimentos de diferentes disciplinas escolares.
